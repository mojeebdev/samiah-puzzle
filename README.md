# 🧩 Samiah's 27th Birthday Puzzle Game 🎂

A custom-built, mobile-responsive puzzle game created as a special 27th birthday gift. The game features a 27-piece ($3 \times 9$) interactive puzzle designed from a personal portrait, a real-time leaderboard, and session management.

## ✨ Features

- **Symbolic Gameplay:** Exactly **27 pieces** for a **27th birthday**.
- **Real-time Leaderboard:** Friends can compete for the fastest time. Scores update instantly via Firebase Firestore.
- **Identity Lock:** A 3-hour "Username Lock" prevents leaderboard spamming and keeps the competition fair.
- **Mobile First:** Designed specifically for mobile browsers with touch-friendly "Tap-to-Swap" logic.
- **Celebratory UI:** Integrated confetti animations upon puzzle completion.

## 🚀 Tech Stack

- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Database:** [Firebase Firestore](https://firebase.google.com/) (Real-time updates)
- **Animation:** Canvas-confetti
- **Styling:** CSS-in-JS (for cross-browser compatibility)
